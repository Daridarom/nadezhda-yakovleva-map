# Надежда Яковлева — «Карта внутренних территорий»

Адаптивный одностраничный сайт психолога Надежды Яковлевой.

[Открыть сайт Надежды](https://daridarom.github.io/nadezhda-yakovleva-map/) — публичная версия на GitHub Pages, без входа в аккаунт.

## Версия от 14 сентября 2026

- Чёткий портрет на первом экране и реальный морской снимок в разделе «Обо мне».
- Темы для обращения раскрываются сразу под названием.
- Убраны переключение резкости, декоративные взаимодействия, отдельная галерея и поиск по ключевым словам.
- Упрощены навигация и запись через Telegram.
- Исправлены мобильное меню, переносы и положение выбранной темы под закреплённой шапкой.

## Запуск

Статический сайт без сборки. Опубликуйте содержимое корня на статическом хостинге или запустите `python3 -m http.server 8080` и откройте `http://localhost:8080`.

`index.html` — содержание; `styles.css` — оформление; `script.js` — меню и темы; `assets/` — фотографии и локальные шрифты. Проверено в Chromium на широком и узких экранах, включая управление с клавиатуры.

Контакт для записи: https://t.me/nv_yaya. Условия консультации согласуются лично. Профессиональные тексты остаются первичной редакционной версией.

Фотографии предоставлены для сайта; права на изображения принадлежат правообладателям. Лицензии Cormorant и Inter: `FONT-LICENSES.txt`.
