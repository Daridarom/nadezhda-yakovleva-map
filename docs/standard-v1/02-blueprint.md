# Standard v1 — Blueprint

## 1. Цель и границы
Одностраничный персональный сайт психолога. Главная задача — не «продать терапию любой ценой», а помочь посетителю понять, откликается ли ему Надежда, и безопасно сделать первый шаг через Telegram.

Не входит в текущую версию: личный кабинет, хранение клиентских данных, оплата, медицинская диагностика, автоматическое принятие решений о клиенте, полноценная CRM.

## 2. Информационная архитектура
1. Hero — кто Надежда, эмоциональный тезис, главный CTA.
2. «С чем можно прийти» — маршруты/темы как точки узнавания себя.
3. «Обо мне» — личный образ + профессиональная позиция.
4. Образование и документы — подтверждение квалификации.
5. «Инструменты» — как устроена работа без обещаний результата.
6. Пространство — психологический центр + «Нараяна», работа с глиной, адрес.
7. Первая встреча — три шага и ожидания.
8. Финальный CTA — простой переход в Telegram.

## 3. Основные состояния и действия
- раскрытие одной из тем маршрута;
- прокрутка с визуальным маршрутом;
- включённое/уменьшенное движение;
- мобильное меню;
- переход к документу об обучении;
- переход в Яндекс Карты;
- переход в Telegram;
- работа без JavaScript: контент и контакты остаются доступными.

## 4. Источники данных
- репозиторий — источник опубликованной структуры и кода;
- подтверждённые пользователем данные — адрес, контакты, позиционирование;
- реальные фото/знак Надежды — визуальный источник истины;
- документы об обучении — только как изображения документов, без утверждения о проверке по реестрам;
- внешние профессиональные профили используются как редакционный источник, но не должны становиться скрытым API-источником или внешней зависимостью сайта.

## 5. Design system
### Типографика
Cormorant — эмоциональные заголовки и акценты; Inter — интерфейс и основной текст.

### Визуальный язык
- молочно-песочная база;
- спокойная зелёно-земляная палитра для маршрута;
- синий Morpho как фирменный акцент;
- реальные фотографии крупнее декоративной графики;
- карта/линия пути как один сквозной motion-мотив.

### Motion rule
Одновременно не должно конкурировать более одного сильного движения. Бабочки поддерживают образ, но не перекрывают лицо, CTA и чтение. При reduced-motion — статичное состояние.

## 6. Компоненты
- header + desktop/mobile nav;
- hero copy + portrait;
- CTA primary/secondary;
- route accordion;
- about/profile block;
- credentials/cards;
- tools cards;
- clay/workshop block;
- address/map block;
- first-meeting steps;
- final CTA;
- journey SVG + decorative Morpho layer.

## 7. Интеграции и права
### Telegram
Только outbound-link на @nv_yaya. Нет отправки сообщений от имени пользователя и нет автоматической записи.

### Яндекс Карты
Ссылка/встраивание только для подтверждённого адреса. Не переносить рейтинги, отзывы и часы работы без отдельной проверки.

### Внешний CDN документов
Текущие изображения дипломов загружаются с внешнего CDN. Желательная следующая техническая задача — локальная копия разрешённых документов для устойчивости и контроля зависимостей.

## 8. Безопасность и приватность
- никаких секретов/API-ключей в статическом репозитории;
- нет клиентских форм и баз данных в текущей версии;
- любые будущие формы должны иметь отдельную политику обработки данных и минимальный набор полей;
- не подключать сторонние analytics/tracking автоматически;
- содержание консультаций не использовать в общей рабочей AI-памяти;
- внешние скрипты и MCP не добавлять без review.

## 9. Вертикальные срезы
### Slice A — доверие первого экрана
Hero + живой портрет + ясный CTA + mobile.

### Slice B — узнавание себя
Маршруты/темы + контент + доступность accordions.

### Slice C — доверие к специалисту
About + 10 лет опыта + специализации + документы.

### Slice D — как проходит работа
Инструменты + первая встреча.

### Slice E — физическое пространство
Глина + адрес + карта.

### Slice F — release quality
SEO/OG + reduced motion + no-JS + performance + link checks.

## 10. Acceptance criteria
- один главный CTA на первом экране;
- визуальный акцент hero не конкурирует с motion;
- все шесть тем читаемы с клавиатуры и touch;
- профессиональные утверждения имеют источник;
- дипломы не описываются как «проверенные по реестрам», если этого не было;
- адрес один и тот же во всех местах;
- нет цены/длительности, пока они не подтверждены;
- CTA ясно сообщает, что откроется Telegram;
- mobile 320–430 px не ломается;
- reduced-motion отключает декоративное движение;
- критические внешние ссылки проверены;
- итоговый визуальный ритм не ощущается как каталог из одинаково громких секций.
